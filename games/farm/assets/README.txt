BỘ HÌNH CHO GAME NÔNG TRẠI VUI
==============================

Các file .png trong thư mục này được cắt từ bộ sprite (texture-0/1.png) của
game "Idle Farming Business" do MarketJS làm (bản chạy trên CrazyGames).

!! CHỈ DÙNG Ở MÁY CÁ NHÂN !!
Hình ảnh thuộc bản quyền MarketJS. Nếu đưa GameVui lên mạng công khai
(GitHub public, GitHub Pages...), hãy XOÁ các file .png này hoặc thêm dòng
    games/farm/assets/*.png
vào .gitignore — game sẽ tự chuyển sang bộ hình vẽ/emoji dự phòng.

Game cần ĐỦ tất cả các file; thiếu bất kỳ file nào thì toàn bộ game dùng
hình dự phòng.
